# Linux Basic Commands Lab

I practiced basic Linux commands in Hack The Box Academy as part of my cybersecurity training.

## Commands practiced

- `whoami` — Display current username
- `pwd` — Show current directory
- `ls -la` — List files, including hidden files
- `mkdir` — Create a directory
- `touch` — Create a file
- `cp` — Copy files
- `mv` — Move or rename files
- `chmod` — Change file permissions
- `chown` — Change file ownership
- `find` — Search for files

## What I learned

Linux navigation, file management, and permissions.
